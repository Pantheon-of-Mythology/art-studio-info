Personal art tools

A home for references
and the notes behind them.

Pantheon Art Studio is a personal, locally run tool for organizing illustration references, recording study notes, and keeping original images and metadata in a private Google Drive library.

The current workbench

Browse references at full resolution, search and filter the library, and edit descriptions, tags, character links, sources, and study notes. Save changes locally, sync originals and catalog metadata to Drive, or restore missing local originals from the library.

The workbench runs on the user’s computer and opens in a browser through a local loopback connection. This website provides app information; it does not host the private gallery, accept image uploads, or offer public accounts. Animation workflows are a future direction, not a current feature.

Google Drive connection

The Google authorization screen may identify this connection as Pantheon TD Art Library. The tool uses Google OAuth to connect directly to Google Drive. It requests full Drive access because the existing private library was created by another application; its implemented transfers are confined to the configured library folders.

Connecting Google is optional. Read the privacy policy for the data involved, where it is stored, and how to remove access.
