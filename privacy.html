Privacy policy

Last updated: November 9, 2026

Pantheon Art Studio is a personal reference library and metadata authoring tool that runs on the user’s computer. Its Google OAuth connection may appear as Pantheon TD Art Library. This policy covers the local tool and this informational website.

Data the tool uses

The tool processes the original images you add, image dimensions and SHA-256 hashes, catalog descriptions, tags, character links, sources, rights notes, and other study metadata you record. Local copies, transfer state, and verification receipts are stored on your computer.

When you connect Google, the tool receives authorization tokens and reads Google Drive file and folder metadata needed to verify the configured library. When you request a sync or restore, it transfers original images and catalog metadata between your computer and that private Drive library. Catalog snapshots and hashes support verification and recovery.

Google access and its purpose

The tool requests the full Google Drive permission, https://www.googleapis.com/auth/drive. This permission can grant broad access to your Drive files. It is needed here because the existing library was created by another application. The tool confines its implemented library operations to configured folders and verifies owner-only access to the library objects it uses.

Google sign-in uses Google’s OAuth service. Authorization and Drive API requests go directly from the local tool to fixed Google HTTPS endpoints. The browser workbench uses a loopback connection to the local server; there is no Pantheon-hosted server relaying your library or Google credentials.

Storage and sharing

Google client configuration and the refresh token are stored in the local .env credential file, excluded from Git. Access tokens are held in the local server’s memory. Tokens are not returned to the browser workbench or saved in browser storage.

Original images, catalog metadata, hashes, and snapshots synced to Drive remain in the configured private Google Drive library. The tool does not make these files public or change their sharing settings to share them with others.

The tool does not sell personal data, send it to advertising or analytics services, or share it with third parties beyond Google for the Drive connection you request. It does not use Google user data to train AI models. Google processes the data sent to its services under its own policies.

Retention and your controls

Local files and Drive library files remain until you remove them. Syncing retains catalog snapshots for recovery; removing an entry from a catalog does not by itself erase every saved copy or snapshot.

You can revoke the application’s access through your Google Account connections. To remove the local authorization, stop the tool and remove its stored refresh token from the local credential file. Removing local authorization does not revoke Google’s grant or delete files from Drive; revoke the connection in your Google Account to remove that grant.

You can delete local copies from your computer and delete library files you own through Google Drive. Deleting local files or disconnecting authorization does not delete the Drive copies. Deleting Drive files does not remove copies already on your computer.

This website

This static informational site contains no analytics, tracking scripts, third-party fonts, account forms, or image uploads. This site is hosted on GitHub Pages. GitHub logs and stores visitors’ IP addresses for security purposes, whether or not they are signed in to GitHub. See GitHub Pages data collection and the GitHub General Privacy Statement for the provider’s data processing and retention practices.
